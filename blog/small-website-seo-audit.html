How to run an SEO audit on a small website

Start with the pages that matter

Pick a small sample: the homepage, the main service pages and the page where people enquire or book. For each one, write down the action the page should support and the type of search that might bring someone there. A course page should help a prospective learner assess eligibility, understand the schedule and register. A contact page has a different job.

Check discovery and usefulness

Open each page from the site navigation and on a phone. Check that internal links work and that the title and main heading describe the same offer. If you have Search Console access, use URL Inspection to check the indexed URL and compare it with the URL you intend to show in search. Record the evidence beside each finding, including the affected URL and the date you checked it.

Prioritise the fixes

Put blocked journeys ahead of cosmetic improvements. A broken registration link deserves attention before a slightly repetitive heading. For each fix, record the owner, the expected improvement and how you will check it. Re-test the journey after publication, then compare organic clicks and enquiries with a baseline. The Intech Centre audit illustrates how to turn public observations into recommendations.
