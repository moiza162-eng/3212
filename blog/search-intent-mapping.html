Map search intent before writing a page

Look for the task behind the query

Someone searching for a digital marketing course in London may want to compare providers. Someone searching for the name of a specific qualification may be looking for eligibility details or registration. Read the results for a few representative queries and note which formats appear: directories, course pages, guides or booking pages. Treat this as evidence of likely intent, not a guarantee.

Give each page a job

Build a simple map with columns for query theme, user task, preferred URL and next action. A comparison guide can help readers choose between a short introductory course and a qualification. The course page should answer the practical questions that follow: entry criteria, delivery format, assessment and how to apply.

Check before creating another page

Review existing pages against the map. If two pages cover the same task, compare their search queries and performance in Search Console where available. Decide whether either page earns its own place through a distinct purpose. Update internal links so their wording helps readers choose the right page. After changes, watch which URLs receive clicks for each query theme.

Start with language your audience uses

Gather examples from enquiry emails, comments, on-site search and conversations with customer-facing staff. A training team might hear people ask whether a course is free, whether they can attend after work and whether the qualification is recognised. Keep the language used by prospective learners, since phrases from an internal brochure may describe the same offer differently. Group queries that point to a common task and record examples in the map. Include the evidence behind each grouping so a colleague can revisit it later. A phrase that appears often may still be a poor fit if the organisation cannot meet the audience's expectations.

Handle queries that can mean two things

A phrase like “digital marketing training” might describe someone looking for a qualification, advice for a team or a short online tutorial. Check several related searches and note how the results change when someone adds a location, a qualification level or a word like “online”. Where the results show a mix of formats, treat the task as a hypothesis. Use page feedback and the questions visitors ask after landing to refine it. A concise comparison page can help readers with broad intent understand the options, while a course page can serve readers who know which qualification they want. The wording on each page should make its purpose clear within a few lines.

Translate the map into a brief

For each priority page, write a short brief naming the audience, the question it answers and the next action. For a comparison guide, include course length, attendance patterns and who each option suits. For a registration page, confirm the entry criteria and what happens after the form is sent. Ask whoever owns the offer to check that the brief reflects current details. Then review the title, main heading and internal links together. A guide linking to a course using the course name gives visitors a better clue than a string of links labelled Learn more. Use natural language throughout, particularly for links and wordings that are read out by assistive technology.

Update the map as new evidence arrives

Record the preferred page and note any exceptions, such as a time-limited campaign page. After launch, check whether queries are reaching the intended pages and whether visitors take the next step. If a guide brings many readers who later navigate to a course, that can be useful even if relatively few register directly from the guide. If search clicks consistently reach an old announcement, assess whether it still helps readers and add a clear route to current details. Avoid assigning a new page to every slight variation of a phrase. Review the map when offers or locations change. During each review, trace at least one complete journey from a broad search to a realistic next step and note any decisions that visitors still struggle to make.

Give the map a named owner and store it beside the content calendar. When someone proposes another article, they can check whether an existing page already answers the question and would benefit from an update instead.
